# VocalGuard 🛡️

**AI-Powered Real-Time Detection of Voice Cloning Impersonation Attacks.**

*A frontend prototype built for SIH Problem Statement **26104**.*

VocalGuard is an enterprise-grade neural framework interface designed to detect deepfakes, synthetic speech, and cloned voices in real-time. It provides a control-room dashboard to monitor intercepted audio streams across VoIP, mobile, and enterprise platforms to prevent financial fraud before authorization.

## 🚀 Core Features
- **Live Operations Console:** Real-time waveform visualization and deterministic threat scoring.
- **Multi-Source Input:** Test deepfake models against live microphone streams or uploaded audio/video files.
- **Granular Telemetry:** Displays underlying `Spectral Phase` consistency and `Prosody Variance` metrics.
- **Cyber-Industrial Design:** Built with a bespoke, high-contrast brutalist design system.

## 🛠️ Tech Stack
- **React** (Component Architecture)
- **Vite** (Lightning-fast Build Tool)
- **Tailwind CSS v4** (Utility-first Styling)
- **Lucide** (Technical Iconography)

## ⚡ Quick Start

1. **Install the dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open the platform:** 
   Navigate your browser to `http://localhost:5173`
